① 概要

OpenWeather（OpenWeather Ltd.）は、世界各地の気象データを API として提供する気象データプロバイダである。
Web・モバイル・地図アプリケーション向けに、現在の天気、短期・中期予報、気象警報、地図用気象レイヤー、ルート上の気象リスクなどを提供している。

提供されるデータは、数値予報モデル、衛星データ、レーダーデータ、地上観測データなど複数のソースを統合・処理したもので、地点指定（緯度・経度）を基本とする API 形式で配信される。
そのため、地図上での移動体（人・車両）の現在地や将来位置に対し、天候情報を直接ひも付けて利用できる。

会社の本拠地は 英国（ロンドン） にあり、提供する API は 国・地域を限定せず、世界中の地点を対象としている。
日本についても、緯度・経度指定による取得が可能であり、日本の地図上での利用に対応している。

また、国の気象警報については、各国の公的機関を情報源として統合しており、日本の警報データも対象に含まれている。

出典（データの取得元）

予報・現在値等：OpenWeather 独自の数値予報モデルおよび、衛星・レーダー・地上観測データの統合処理

国の気象警報：各国の公式警報機関（日本は Japan Meteorological Business Support Center）

参考：URL
https://docs.openweather.co.uk/api/one-call-3

https://docs.openweather.co.uk/api/road-risk

https://find-and-update.company-information.service.gov.uk/company/11047846

② 特色（他の地図系APIと比べて何が強いか）
特色1：天気系の複数要素を「1回の取得」にまとめる One Call API がある

One Call API 3.0 は、現在・分単位・時間別・日別予報＋政府（国）の気象警報までを「One Call API 3.0 contains 5 endpoints」として整理し、まとめて扱えるプロダクトとして説明されています。
（地図アプリ側では、調査員/車の現在地（lat/lon）に対して「今〜近未来〜数日＋警報」を一貫した形で取り回しやすい、という意味で“まとめ取り”が強みになります。）

参考：URL
https://docs.openweather.co.uk/api/one-call-3

特色2：地図に重ねやすい “Weather maps 2.0” を公式提供（タイル/レイヤー）

Weather maps 2.0 は URL 形式で地図レイヤー（15レイヤー）を取得でき、Leaflet/OpenLayers 等でレイヤー表示する前提の説明が明記されています。
参考：URL
https://docs.openweather.co.uk/api/weather-map-2

特色3：“移動（ルート）”に寄せた Road Risk API がある（ただし日本は一部機能非対応）

Road Risk API は ルートを「緯度・経度・時刻の点列」として渡し、各点の気象＋国の警報を返すコンセプトです。
加えて、路面温度・ブラックアイス（路面状態）は US/EU のみ提供と明記されているため、ここは日本では非対応です。
参考：URL
https://docs.openweather.co.uk/api/road-risk

■One Call API 3.0（統合気象データ取得API）
1つの地点（緯度・経度）に対して、以下の 複数種類の天候データを1レスポンスで取得できる統合API。

現在の天気、気温、体感温度、風速・風向、降水量、雲量など
参考：https://docs.openweather.co.uk/api/one-call-3

■Road Risk API（ルート単位の気象リスク評価API）
移動ルートを「時刻付きの座標点列」として渡すことで、
そのルート上の各地点・各時刻における 気象条件と国の警報情報を返すAPI。

路面温度・ブラックアイス（路面凍結状態）は日本では取得不可

参考：https://docs.openweather.co.uk/api/road-risk

■Weather Maps 2.0（地図タイル型・気象レイヤーAPI）

降水・雲量・気温・風などの気象情報を、
地図タイル（z/x/y）形式の画像レイヤーとして取得できるAPI。

参考：https://docs.openweather.co.uk/api/weather-map-2

■Air Pollution API（大気汚染データAPI）

指定した地点の 大気汚染状況を取得できるAPI。

PM2.5 / PM10
NO₂ / SO₂ / CO / O₃

参考：https://docs.openweather.co.uk/api/air-pollution

■Geocoding API（地名と座標の相互変換API）

地名 → 緯度・経度
緯度・経度 → 地名
を相互に変換するAPI。

参考：https://docs.openweather.co.uk/api/geocoding-api
