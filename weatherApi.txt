WeatherAPI.com（Weather API）
① 概要

提供元（会社・国）
WeatherAPI.com は、OPLAO FZCO（アラブ首長国連邦・ドバイ） により運営されている気象データ提供サービスです。REST 形式の API を通じて、気象および関連データを提供しています。

日本対応
WeatherAPI.com は 全世界を対象としており、日本国内の地点についても都市名、郵便番号、緯度・経度指定によるデータ取得が可能です。

出典（データ取得元）
WeatherAPI.com が提供する気象データは、世界中の公的および民間の気象観測ステーション、ならびに複数のデータプロバイダから取得された観測データを基にしています。
リアルタイムデータは観測データベースから提供され、予報データは複数の気象モデルと機械学習処理を組み合わせて生成されています。

参考：URL
https://www.weatherapi.com/

https://www.weatherapi.com/about.aspx

② 特色（他の地図系・気象系 API と比べての強み）

WeatherAPI.com は、現在の天気、予報、過去データに加え、天文情報、タイムゾーン、大気質、気象アラート、位置検索などを 単一の API 群として提供しています。
レスポンス形式は JSON および XML に対応しており、公式ドキュメントおよび API Explorer により仕様確認が可能です。
また、複数地点をまとめて取得できる Bulk API が提供されています。

参考：URL
https://www.weatherapi.com/docs/

https://www.weatherapi.com/api-explorer.aspx

Current weather or realtime weather API method allows a user to get up to date current weather information in json and xml.
