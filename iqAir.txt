① 概要（会社・日本対応・出典）

**IQAir API（通称：AirVisual API）**は、
指定した場所の「空気の汚れ具合（大気質）」を数値データとして取得する APIです。

会社：IQAir

所在国：スイス

日本対応：対応している（日本の都市・観測地点データあり）

出典（どこからデータを取得しているか）

IQAir が公式に明示しているデータソースは以下です。

地上の大気質観測局（政府・自治体・研究機関）

IQAir 自社および提携センサー

衛星由来の大気質データ

気象データ（風・湿度・気圧など）

参考：
https://www.iqair.com/about-iqair

https://www.iqair.com/air-quality-monitors/api

② 「大気質」とは何か（APIが返す対象）

**大気質（Air Quality）**とは、
空気中に含まれる人の健康に悪影響を与える汚染物質の量です。

IQAir API が扱う主な対象は以下。

PM2.5

PM10

NO₂

SO₂

CO

O₃

これらの濃度を AQI（Air Quality Index） という
「健康影響基準の数値」に変換して提供します。

参考：
https://www.iqair.com/air-quality-index

https://www.iqair.com/world-air-quality-report

③ API名と「何ができるAPIか」

ここが本体です。
API名＝取得できるデータの粒度・意味をそのまま書きます。

AirVisual Community API

概要
国・都市単位での 代表的な大気質（AQI）と汚染物質濃度を取得できる API。

できること

国一覧・都市一覧の取得

都市レベルの AQI 取得

都市レベルの汚染物質濃度取得

大気質に関連する気象データ取得

参考：
https://www.iqair.com/air-quality-monitors/api

AirVisual Startup API

概要
Community API の内容に加え、
実際の観測局（station）単位の大気質データを取得できる API。

できること

観測局単位の AQI 取得

観測局単位の汚染物質濃度取得

都市代表値より細かい実測データ取得

参考：
https://www.iqair.com/air-quality-monitors/api

AirVisual Enterprise API

概要
大規模利用向けに、
世界都市レベルでの大気質比較・ランキングデータを取得できる API。

できること

世界都市の AQI ランキング取得

広域・統計用途向けの大気質データ利用

参考：
https://www.iqair.com/air-quality-monitors/api

④ 他の地図系APIと比べたときの位置づけ

IQAir API は 地図を描画しない

交通・渋滞・経路探索は扱わない

空気の健康リスクを数値で返すことに特化

「地図API」ではなく
**地図に重ねる“環境リスクデータAPI”**です。

参考：
https://www.iqair.com/world-air-quality
