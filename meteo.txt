Open-Meteo 概要

Open-Meteo は、世界中のオープンな数値気象データを統合し、
緯度・経度指定で天候情報を取得できる オープンソースの気象 API サービス である。

運営主体はスイス所在の法人 Open-Meteo GmbH。
利用規約ではスイス法準拠が明記されており、欧州圏を拠点としたサービスであることが確認できる。

Open-Meteo は地図タイルを提供するサービスではなく、
任意地点（緯度・経度）に対する天候データを JSON で返す API であるため、
MapLibre / Google Maps / HERE などの地図上に 天候情報をオーバーレイ表示 する用途に向く。

日本国内についてもグローバル予報モデルで対応しているほか、
気象庁（JMA）の数値予報モデルを利用する日本向け API が提供されている。

出典（データはどこから取得しているか）

Open-Meteo は独自観測網を持たず、
各国の気象機関・国際機関が公開しているオープンデータを統合・再配信 している。

主な出典は以下の通り。

数値予報モデル

ECMWF（欧州中期予報センター）

DWD（ドイツ気象局）

NOAA / NCEP（米国）

CMC（カナダ）

Météo-France

MeteoSwiss

MET Norway

JMA（日本：気象庁）

大気質

Copernicus Atmosphere Monitoring Service（CAMS）

洪水・河川流量

GloFAS（Copernicus Emergency Management）

標高

Copernicus DEM（GLO-90）

Open-Meteo はこれらのデータソースとライセンス条件を公式に明示しており、
「どの機関のデータを使っているか」を説明しやすい点が特徴である。

特色（他の天候系 API と比べた強み）
地域に応じたモデル自動選択

Open-Meteo は単一モデル固定ではなく、
地域ごとに精度の高い数値予報モデルを組み合わせて提供する設計 を採用している。

これにより、日本では JMA、欧州では ECMWF 系といった形で
地域特性を考慮した天候データを取得できる。

参考：https://open-meteo.com/en/docs

APIキー不要（非商用）・オープンソース

非商用利用では APIキー不要 で即利用可能。
さらにバックエンド実装は GitHub 上で オープンソース公開 されており、
データ処理のブラックボックス性が低い。

公共用途・調査用途・研究用途との親和性が高い。

主要な API（endpoint）一覧

/v1/forecast

過去気象（再解析）

/v1/archive
過去の実績気象データ取得

大気質

/v1/air-quality

/v1/marine
