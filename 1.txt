TomTom Traffic API 概要整理（交通情報取得用途）
1. 会社概要・データ提供体制（日本対応含む）

会社名：TomTom

本社所在地：オランダ（アムステルダム）

事業内容：
デジタル地図、ナビゲーション、交通情報（トラフィック）、位置情報プラットフォームの提供

TomTom は自動車メーカー、物流事業者、行政機関向けに、長年にわたり交通情報および走行データを提供している地図・交通情報ベンダー。

トラフィックデータの出典（Floating Car Data）

TomTom の交通情報は、主に Floating Car Data（FCD） を基に生成されている。

実際に走行している車両・デバイスから取得される匿名化データ

位置、速度、移動時間などを継続的に収集

リアルタイム交通状況および予測算出に利用

公式説明：
https://developer.tomtom.com/move-portal/guides/od-analysis/introduction

日本でのデータ対応

TomTom は 日本国内でも交通データを収集・提供している

日本の都市別トラフィック指数が公開されており、国内実データの存在が確認できる

例：
https://www.tomtom.com/traffic-index/city/fukuoka

日本では ZENRIN様と協業しており、日本市場向けのデータ品質向上および提供体制について公式発表が行われている

公式発表：
https://www.zenrin.co.jp/information/public/171027.html

2. TomTom Traffic API の特色
他の地図系 API と比較した際の注目点

大量のプローブデータに基づくリアルタイム性
実走行データ（FCD）を大量に収集し、現在速度や渋滞状況を高頻度で算出できる。

解説：
https://www.tomtom.com/newsroom/product-focus/tomtom-traffic-stats-explained/

地図表示と独立したトラフィック API
地図タイルの利用が必須ではなく、MapLibre などの既存地図基盤と組み合わせて利用できる。

用途に応じた多様な配信方式

REST API（JSON）

表示向けラスタ／ベクタタイル

エンタープライズ向け（DATEX II、Protobuf 等）

3. 利用を想定する主要 API
① Traffic Flow API

道路ごとのリアルタイム渋滞・速度情報を取得する API

この API で分かること

指定した道路について、
現在どの程度の速度で流れており、
通常時と比べてどれくらい混雑しているかを数値で把握できる。

主なレスポンスパラメータ

currentSpeed
現在の平均走行速度
実際にその道路を走行している車両の平均速度

freeFlowSpeed
通常時（自由流）の基準速度
渋滞や混雑がない状態で、その道路が本来出せる速度
（制限速度ではなく、過去の実走行データから算出された比較用の基準値）

currentTravelTime
現在の走行時間
現在の交通状況を反映した道路区間の通過時間

freeFlowTravelTime
自由流時の走行時間
混雑がない場合に想定される道路区間の通過時間

これらの値を比較することで、渋滞の有無や遅延量を定量的に評価できる。

想定用途

道路単位の渋滞可視化

地域ごとの混雑度の数値化

MapLibre + ZENRIN様 地図への独自オーバーレイ表示

地図描画を伴わない交通指標提供

公式ドキュメント

https://developer.tomtom.com/traffic-api/documentation/traffic-flow/flow-segment-data

API	取得できる情報	主な役割

5. 想定システム構成との適合性

地図表示：MapLibre + ZENRIN様

交通情報取得：TomTom Traffic API

地図基盤と交通データを分離することで、

既存の地図資産を活用しつつ

リアルタイム交通情報のみを API で取得・更新

する構成が可能となり、柔軟性と拡張性の高いシステム設計に適している。



Traffic Incidents

Traffic Incidents は、道路ネットワーク上で発生している 交通上の異常や支障となる出来事 を取得するためのサービスである。

事故、道路工事、通行止め、車線規制など、通常の交通の流れを妨げる一時的な事象を対象としており、
それぞれの事象について、

どこで発生しているのか

どの道路・区間に影響しているのか

どの方向に影響があるのか

どの程度交通に影響を与えているのか

といった情報を把握できる。

渋滞の「結果」だけでなく、渋滞が発生している原因や背景となる事象を可視化できる点が特徴であり、
リアルタイムな注意喚起、交通状況の分析、混雑要因の把握などに利用される。

公式ドキュメント（Traffic Incidents API 一覧）
https://developer.tomtom.com/traffic-api/documentation/traffic-incidents

Traffic Flow

Traffic Flow は、道路ネットワーク上の主要道路について、現在の交通の流れを数値として取得するためのサービスである。

各道路区間ごとに、

現在どの程度の速度で車両が走行しているか

通常時（混雑のない状態）と比べてどれくらい遅れているか

現在の走行時間と、通常時の走行時間の差

といった情報を、リアルタイムの観測データに基づいて提供する。

これにより、道路ごとの混雑度や遅延状況を定量的に把握でき、
地図表示を伴わない交通指標の提供や、独自地図上へのオーバーレイ表示、
地域単位・路線単位での混雑分析などに利用できる。

公式ドキュメント（Traffic Flow API 一覧）
https://developer.tomtom.com/traffic-api/documentation/traffic-flow
