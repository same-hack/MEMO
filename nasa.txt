NASA Earthdata（黄砂対応を含む）解説
① 概要

（運営主体／日本対応／出典＝データ取得元）

運営主体（どこの国の会社か）

NASA Earthdata は、**アメリカ合衆国の政府機関 NASA（National Aeronautics and Space Administration）**が運営する、地球観測データの公式配布・検索基盤である。
企業サービスではなく、NASA の地球科学データを一般公開するための国家プロジェクトとして提供されている。

参考：https://www.earthdata.nasa.gov/

日本の地図は対応しているか

Earthdata は道路地図やナビ地図を提供するサービスではないが、地球全域（全球）を対象とした観測データを扱っているため、日本列島および周辺海域は完全に対象範囲内である。
日本上空を通過する衛星観測データ、再解析データ、画像タイルはすべて利用可能である。

参考：https://www.earthdata.nasa.gov/about/earthdata-cloud-evolution

出典（どこからデータ取得しているのか）

Earthdata で提供されるデータの主な出典は以下のとおり。

NASA 自身の地球観測衛星ミッション

MODIS（Terra / Aqua）

VIIRS

その他 Earth Observing System（EOS）系ミッション

NASA が統合・再解析したモデルデータ

MERRA-2（エアロゾル・大気再解析）

NASA が公式に統合している他機関データ

NOAA

ESA

JAXA 等

Earthdata は「NASA データのみ」に限定されず、公式に統合された地球科学データの検索・配信基盤として機能している。

参考：https://www.earthdata.nasa.gov/data/tools/earthdata-search

参考：https://www.earthdata.nasa.gov/about/earthdata-cloud-evolution

② 特色

（他の地図系 API と比べて何が強いか）

黄砂を「エアロゾル（Aerosol）」として直接扱える

NASA Earthdata では、**黄砂はエアロゾルの一種（Dust）**として定義されている。
これは単なる視覚表現ではなく、物理量として観測・解析されたデータである。

エアロゾル光学的厚さ（Aerosol Optical Depth / AOD）

砂塵（Dust）成分

煙・大気汚染物質との識別

Google Maps 等の地図 API では扱えない、大気中粒子レベルの環境要因を直接取得できる点が最大の強みである。

参考：https://www.earthdata.nasa.gov/learn/backgrounders/aerosols

地図タイルとして直接重ねられる（GIBS）

NASA GIBS を使うことで、黄砂・砂塵の分布を WMTS / WMS タイルとして取得できる。
これは MapLibre、OpenLayers、Leaflet 等の地図ライブラリと親和性が高い。

日付指定可能（time dimension）

全球対応

追加の前処理不要

参考：https://nasa-gibs.github.io/gibs-api-docs/access-basics/

数値データとして取得できる（API）

NASA POWER API を利用すると、地点・期間指定でエアロゾル量（AOD）を数値として取得できる。
これにより「見える黄砂」ではなく、判定・アラート・遅延要因分析に使える数値として扱える。

参考：https://power.larc.nasa.gov/docs/services/api/

③ 主要な API（endpoint）と公式ページ
1. NASA GIBS（衛星画像・黄砂可視化）

概要
衛星観測画像・解析画像を WMTS / WMS タイルとして配信するサービス。

主な用途

黄砂（砂塵）の広がりを地図上に表示

調査員・調査車の現在地と重ね合わせ

エンドポイント

https://gibs.earthdata.nasa.gov/wmts/epsg4326/best/
https://gibs.earthdata.nasa.gov/wms/epsg3857/best/wms.cgi


公式ドキュメント
参考：https://nasa-gibs.github.io/gibs-api-docs/access-basics/

参考：https://www.earthdata.nasa.gov/news/blog/wmts-time-dimensions-restful-access

2. NASA POWER API（黄砂を数値で取得）

概要
気象・太陽放射・エアロゾル等を REST API で取得する公式サービス。

黄砂関連で取得可能な代表パラメータ

Aerosol Optical Depth（AOD）

エンドポイント

https://power.larc.nasa.gov/api/temporal/daily/point


公式ドキュメント
参考：https://power.larc.nasa.gov/docs/services/api/

参考：https://power.larc.nasa.gov/docs/tutorials/api-getting-started/

3. CMR API（データ検索・取得）

概要
NASA Earthdata 全体のメタデータ検索基盤。
MODIS、MERRA-2 等の黄砂関連データセットを検索・取得するための API。

エンドポイント

https://cmr.earthdata.nasa.gov/search/


公式ドキュメント
参考：https://cmr.earthdata.nasa.gov/search/site/docs/search/api

参考：https://www.earthdata.nasa.gov/about/esdis/eosdis/cmr

4. Earthdata Login（認証）

概要
一部データ取得時に必要な NASA 公式認証基盤。

URL

https://urs.earthdata.nasa.gov/


参考：https://www.earthdata.nasa.gov/data/earthdata-login/guidance
