① 概要（何ができるか／どこの国の会社か／日本対応／出典）
TomTom Traffic APIs とは（何ができるか）

TomTom の「Traffic APIs」は、主に リアルタイム交通（渋滞＝Traffic Flow、事故・規制＝Traffic Incidents） と、別系統として 過去の統計交通（Traffic Stats / Historical Traffic） を扱う API 群です。リアルタイム系は REST API として、地図上への重畳表示（タイル）や、座標近傍の道路リンクの速度・所要時間/渋滞度、事故・工事・通行止めなどの事象取得に使えます。

参考：URL
https://developer.tomtom.com/traffic-api/documentation/tomtom-maps/product-information/introduction

https://developer.tomtom.com/traffic-api/documentation/tomtom-maps/traffic-flow/traffic-flow-service

https://docs.tomtom.com/traffic-api/documentation/tomtom-maps/traffic-incidents/traffic-incidents-service

TomTom は オランダ（Amsterdam, The Netherlands） の企業（TomTom N.V.）です。

https://www.tomtom.com/impressum/

日本の地図・交通は対応しているか（重要）

結論から言うと、「Developer Portal の Traffic API（Traffic Flow / Incidents）の Market Coverage 一覧」には日本（Japan / JP）が掲載されていません。このページは「一覧に無い market はサポートされない」と定義しており、少なくとも この Traffic API（TomTom Maps の Traffic Flow/Incidents）としては日本がサポート対象外と読み取れます。

一方で、Traffic Stats API（過去統計） の Market Coverage には Japan (JP) が掲載されており、「選定都市に限定される可能性がある」旨も記載されています。

参考：URL
https://developer.tomtom.com/traffic-api/documentation/tomtom-maps/product-information/market-coverage

https://developer.tomtom.com/traffic-stats/documentation/product-information/market-coverage

※補足（矛盾の扱い）
TomTom 自体は日本での交通サービス提供をうたう発表や、第三者（パートナー）側の発表も存在しますが、**「開発者向け Traffic API の日本対応」**という観点では、一次ソース（Market Coverage）が日本を含んでいないため、ここでは **「Traffic API は日本対応が確認できない（＝サポート外扱い）」**を結論にしています。

② 特色（他の地図系APIと比べて何が強いか）

「地図表示用のタイル」と「分析/取得用の非タイル」を両方持つ
Traffic Flow / Incidents ともに、**地図に重ねるタイル（Raster / Vector tiles）**と、**座標やBBoxで取得する非タイル（例：Flow Segment Data / Incident Details）**が用意されています。UI用途（重畳表示）と、ロジック用途（遅延検知・アラート判定）を分けて実装しやすいのが強みです。

更新頻度を明記（“every minute”）している
Traffic Flow/Incidents について、少なくともドキュメント上は 毎分更新が明記されています（リアルタイム監視の根拠にしやすい）。

データソースを“複数統合”として説明している
スマホ、車載/ナビ、フリート、政府センサー等の統合という説明は、品質/カバレッジの説明として採用しやすいです。

Historical（Traffic Stats）系を別体系で提供
過去の速度・所要時間統計（Route/Area Analysis）を API として提供しており、リアルタイムだけでなく「平常時平均との差」「曜日/時間帯平均との差」「ボトルネック特定」などの分析系に繋げやすいです。

Traffic Flow（渋滞・速度・所要時間）

Flow Segment Data (get)

https://developer.tomtom.com/traffic-api/documentation/tomtom-maps/traffic-flow/traffic-flow-service

Raster Flow Tiles (get)
渋滞の色分け等をラスタタイル（256/512px）で配信。
参考：URL
https://developer.tomtom.com/traffic-api/documentation/tomtom-maps/traffic-flow/traffic-flow-service

Vector Flow Tiles (get)

参考：URL
https://developer.tomtom.com/traffic-api/documentation/tomtom-maps/traffic-flow/traffic-flow-service
