以下は 公益財団法人日本道路交通情報センター（JARTIC）が提供する OpenTrafficAPI（正式には交通量 API） について、地図アプリの API 選定用途で知りたいポイントを 公式ソースに基づいてまとた整理 した説明です。

1. 概要 — どこの国／組織の API か？日本の地図は対応しているか

OpenTrafficAPI（交通量 API） は

国：日本

提供組織：公益財団法人 日本道路交通情報センター（JARTIC）

内容：国土交通省道路局が設置した機器で 機械観測された全国の直轄国道の方向別交通量データ を API で取得できる機能です。

地図対応：位置情報（緯度・経度）付き交通量データを取得できるため、日本の地図上で可視化できます。

提供形式：GeoJSON または CSV（WFS 準拠）で取得可能です。

更新頻度：

5 分間値（観測から約 20 分後に取得可能、過去約 1 ヶ月分）

1 時間値（観測後毎時約 20 分後、過去約 3 ヶ月分）
が提供されています。
これらは 国土交通省から提供されたデータを JARTIC がホストして API で公開している もので、商用地図ベンダーのリアルタイム推定値ではありません。

2. 出典（データソース）は何か

この API の元データは次のように整理されています：

国土交通省道路局 が設置した観測機器による 交通量の実測データ

常設トラフィックカウンター（超音波式等の観測機器）

CCTV トラフィックカウンター（AI による CCTV 映像解析）

観測地点数は全国約 2,600 箇所。

方向別の交通量データと観測地点の位置情報を組み合わせて提供。

提供には JARTIC のガイダンスサイトを通じて API 利用規約への同意が必要。

この API は Google Maps や ZENRIN など民間地図ベンダー独自のデータではなく、国の観測データが原データ です。

3. 特色（他の地図系 API と比べて何が強いか）
（1）データの性質

実際の観測データ に基づく交通量情報を取得可能です。推定データではなく、計測値が返ってきます。

（2）形式・基準

データは WFS（OGC Web Feature Service）準拠 で提供され、GeoJSON または CSV を直接取得できます。GIS 系統のアプリとの親和性が高いです。

（3）粒度と更新頻度

5 分間値／1 時間値という細かな集計単位で交通量データが取得でき、最新データの取得が可能です。

4. 地図系 API と比較した特徴
項目	JARTIC 交通量 API	一般的な商用地図 API*
データ元	実観測データ（国土交通省）	ユーザーやプローブデータ等
リアルタイム性	5 分〜20 分遅延実測値	高頻度推定値
カバレッジ	日本国内の直轄国道	世界中の道路
形式	WFS/GeoJSON/CSV	独自 REST/JSON
主用途	交通量解析、統計、可視化	ルート案内、渋滞レベル、ナビ
コスト	無料（利用規約同意要）	有料プランあり

※ 商用地図 API（Google Maps, Here, TomTom など）の交通 API とは用途が異なります。

5. 主要な API（エンドポイント）と仕様
（1）ベース API エンドポイント

交通量 API ベース URL
https://api.jartic-open-traffic.org/geoserver
※ WFS ベースの GeoServer エンドポイントです。

（2）主要なデータ種類（typeNames）

これらは API の typeNames パラメータで指定します。仕様書に記載された代表的な名称は以下です：

t_travospublic_measure_5m

常設トラカン 5 分間交通量データ。

t_travospublic_measure_1h

常設トラカン 1 時間交通量データ。

t_travospublic_cctv_measure_5m

CCTV トラカン 5 分間交通量データ。

t_travospublic_cctv_measure_1h

CCTV トラカン 1 時間交通量データ。

（3）API リクエスト例（構成）

基本的な WFS GetFeature リクエスト例（GeoJSON 形式取得）：

https://api.jartic-open-traffic.org/geoserver?
service=WFS&
version=2.0.0&
request=GetFeature&
typeNames=t_travospublic_measure_5m&
srsName=EPSG:4326&
outputFormat=application/json&
exceptions=application/json&
cql_filter=道路種別=3 AND 時間コード=202505130900 AND BBOX(ジオメトリ,139.65,35.65,139.75,35.75,'EPSG:4326')


service=WFS：OGC Web Feature Service

version=2.0.0：WFS バージョン

typeNames：取得対象データ種別

outputFormat：レスポンス形式（GeoJSON/CSV）

cql_filter：フィルタ条件（道路種別、時間コード、BBOX）
この形式は WFS 標準に準拠しており、GIS 系アプリで扱いやすい構造です。

（4）公式仕様書リンク

交通量 API 仕様書（API リクエストの作成方法）
https://www.jartic-open-traffic.org/action_method.pdf

この PDF に、各種パラメータ対応とレスポンス項目定義が記載されています。

ガイダンスサイト（API 概要ページ）

6. API データ内容と構成

交通量 API で返されるレスポンスは GeoJSON 形式の FeatureCollection です。仕様書によると各フィーチャーは以下のような属性を含みます：

観測地点のジオメトリ（MultiPoint）

地方整備局番号

常時観測点コード

観測年月日、時間コード

上り・下り 小型車・大型車 交通量

車種判別不能交通量

異常フラグ（停電、センサー異常 等）

道路種別
この形式であれば、そのまま地理院地図や OpenStreetMap タイル上に重ねて可視化できます。

7. 注意点と利用条件

利用規約の同意が必要：API 利用前に JARTIC の利用規約への同意が必要です。

精度とカバレッジ：観測条件や機器の状態により精度が変動する場合があります。また対象は直轄国道のみです。

用途の適合性：この API は交通量の観測値取得が目的であり、渋滞「レベル」やルーティング API として使うには追加処理が必要です。
