HERETraffic APIはリアルタイムの交通量とインシデント情報を提供するREST APIです。このドキュメントではTraffic APIを紹介し、主な概念を説明するとともに、リソース、クエリパラメーター、レスポンス構造、データ型に関する例や情報を提供します。

HERETraffic APIは次のユースケースをサポートしています。

JSON形式のリアルタイムの交通量データへのアクセスを提供します。このデータには、各リクエストで定義されている地域の速度および渋滞要素に関する情報が含まれます。また、Traffic APIは交通量に関連する道路セグメントのジオメトリーなどの追加データも提供できます。
各交通事案のタイプと場所、ステータス、開始時間と終了時間、その他の関連データを含む、交通事案に関する集約情報をJSON形式で提供します。このデータは、ルート計算を動的に最適化するのに役立ちます。



Traffic API v7 全体について（前提）

HERE Traffic API v7 は リアルタイム交通データ（交通流とインシデント）の REST API です。
空間条件を指定して、道路ごとの流れやイベントの情報を取得できます。(turn1search0
)

日本では主に Traffic Flow（交通流） が使われ、インシデントの提供は国や地域で制限されます。(turn1search6
)

基本の利用方法や必要パラメータについては Getting Started で解説されています。(turn1search7
)

1. Flow（交通流データ取得）

何ができる API か

指定した範囲（円 / bounding box / corridor）内の 道路ごとのリアルタイム交通状況を取得

返される値には 平均速度（speed）、基準速度（freeFlow）、混雑度（jamFactor） などが含まれる

リアルタイムな渋滞・流れの情報を単純数値で取得できる（地図上で可視化したり、解析に使える）

ここが特長

毎分更新されるリアルタイム交通流情報を返す

道路リンクごとに traffic flow のメトリクスを持っており、道路状況を定量的に扱える

公式での解説（コンセプト）
https://www.here.com/docs/bundle/traffic-api-developer-guide-v7/page/topics/concepts/flow.html

2. Incidents（交通インシデント情報取得）

何ができる API か

道路上で発生している 事故・工事・閉鎖・規制などの事象（インシデント）を取得

イベント名・場所・説明・開始時刻／終了時刻・影響範囲などの情報を返す

ここが特長

リアルタイム交通流とは別に、交通に影響するイベント情報を取得可能

ルート再計画や通知機能に組み込みやすい

提供の注意

国/地域ごとに提供可否が異なるため、日本ではインシデント情報が必ずしも提供されない場合がある（Coverageで確認が必要）。(turn1search13
)

公式のコンセプト説明
https://www.here.com/docs/bundle/traffic-api-developer-guide-v7/page/topics/concepts/incidents.html

3. Traffic Coverage（どの地域で何が提供されるか）

何ができる API か

どの国・地域で Traffic Flow と Incident のデータが利用可能かを確認

日本のカバレッジ（Flow は基本的にあるが Incident は制限の可能性あり）などを調べられる

利用用途例

アプリで “渋滞区間を返すかどうか” を制御する前に、その地域で Incident が使えるかどうかをチェックできる

公式カバレッジ情報
https://www.here.com/docs/bundle/traffic-api-developer-guide-v7/page/topics/coverage-information/traffic.html

4. Advanced / Additional Endpoints（利用に便利な補助機能）
A. Flow availability

何ができる

指定した領域に Traffic Flow 情報があるかどうかの可用性チェック

どのエリアで Flow のデータがそもそもあるかを判断するのに使える

用途

事前チェックとして Flow クエリ前に “このエリアは Traffic Flow 情報が出せるか” を確認できる

（旧バージョン v6 の API に存在したことがドキュメントに残っていますが、v7 の組み合わせでも同様の可用性チェック機能が提供されることがあります。）(turn1search12
)

API の利用シーン（何ができるか）
Traffic Flow 利用シーン

フリート管理で 混雑度を可視化して配車計画に使う

ベース地図上に 渋滞レベルを色分けして表示

指定したルート上の リアルタイム速度低下を取得し、ETA やルート再計算に反映

Incidents 利用シーン

事故・工事・通行止めなどのイベント情報を取得して通知

ナビゲーションで “迂回推奨” や “リアルタイム警告” を実装

緊急車両向けアプリで 問題箇所だけをピンポイント取得

まとめ：主要な API とできること
API / 機能	何ができるか（役割／結果）	備考
Flow（交通流）	道路ごとのリアルタイム速度・混雑度を取得	東京〜地方問わず道路単位の流量情報
Incidents（交通インシデント）	事故・工事など交通影響イベントを取得	地域によっては利用不可
Traffic Coverage	どの地域で Flow/Incident が提供されるかを確認	事前チェック用途
Flow availability	指定エリアに Flow 情報が存在するかを確認	取得前の簡易確認
