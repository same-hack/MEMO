HERETraffic APIはリアルタイムの交通量とインシデント情報を提供するREST APIです。このドキュメントではTraffic APIを紹介し、主な概念を説明するとともに、リソース、クエリパラメーター、レスポンス構造、データ型に関する例や情報を提供します。

HERETraffic APIは次のユースケースをサポートしています。

JSON形式のリアルタイムの交通量データへのアクセスを提供します。このデータには、各リクエストで定義されている地域の速度および渋滞要素に関する情報が含まれます。また、Traffic APIは交通量に関連する道路セグメントのジオメトリーなどの追加データも提供できます。
各交通事案のタイプと場所、ステータス、開始時間と終了時間、その他の関連データを含む、交通事案に関する集約情報をJSON形式で提供します。このデータは、ルート計算を動的に最適化するのに役立ちます。


会社情報（どこの国の会社か）

HERE Technologies はオランダ・アムステルダムに本社を置く 位置情報プラットフォーム企業 です。
長年にわたり地図データやリアルタイム交通情報、位置情報 API/SDK を世界中で提供しています。
https://www.here.com/jp/about

日本での対応

HERE の位置情報プラットフォームは 日本を含む世界 200 以上の国／地域 をカバーしています。
交通情報（Traffic）も日本で利用可能な地域コードとしてリストに含まれており、Traffic Flow（交通流情報）は対応していることが公式カバレッジ一覧で確認できます。
https://www.here.com/docs/bundle/traffic-api-developer-guide-v7/page/topics/coverage-information/traffic.html

※ 日本で Traffic Incident（事故・工事等のインシデント情報） の提供が必ずしも全機能でサポートされているとは限定できません（カバレッジ対象として Flow は明示されていますが、Incident は地域により変わる可能性があります）。
https://www.here.com/docs/bundle/traffic-api-developer-guide-v7/page/topics/coverage-information/traffic.html

2. 出典（地図・トラフィックデータの元）

HERE の地図・トラフィックデータは 自社で収集・統合されたデータ を基盤としています。
リアルタイム交通情報は様々なセンサやプローブ（接続車両など）から集められたデータを統合したもので、単に他社 API のデータを借りているわけではありません。
Traffic API では Traffic Flow（交通流）と Traffic Incidents（事故・イベント）という 2 つのデータ種別を取得できます。
https://www.here.com/learn/blog/how-to-enrich-your-applications-with-real-time-traffic-data-from-here-traffic-api

3. 特色（他の地図系 API と比べて何が強いか）
A. 世界レベルの道路カバレッジ

HERE の交通情報は 70 か国以上の道路ネットワークを網羅する大規模データベースとして提供されています。
https://www.here.com/learn/blog/how-to-enrich-your-applications-with-real-time-traffic-data-from-here-traffic-api

B. リアルタイム交通流（Flow）を数値化

Traffic Flow は単に色分けした渋滞表示ではなく、道路リンク（ある一定の道路区間）ごとの以下の定量指標を返します：

平均速度

基準速度（free flow）

混雑度（Jam Factor）

信頼度
など。
これにより データ分析や最適化に適した数値情報として扱えます。
https://www.here.com/docs/bundle/traffic-api-developer-guide-v7/page/topics/concepts/flow.html

C. 空間クエリ指定で柔軟取得

API では、対象範囲を circle / bbox / corridor などで指定し、関心のある任意エリアの交通情報を取得できます。
https://www.here.com/docs/bundle/traffic-api-developer-guide-v7/page/topics/getting-started/send-request.html

D. リアルタイム更新頻度

Flow（交通流）は約 1 分毎に更新されるため、リアルタイムに近い交通状況を API で取得できます。
https://www.here.com/learn/blog/how-to-enrich-your-applications-with-real-time-traffic-data-from-here-traffic-api

4. 主要な API（Traffic API v7）とできること

HERE Traffic API v7 は REST API 体系でリアルタイム交通情報を取得するサービス です。
https://www.here.com/docs/bundle/traffic-api-developer-guide-v7/page/README.html

以下は 主要な API 機能 と 具体的に何ができるか の説明です。

A. Traffic Flow（交通流情報取得）

できること

指定したエリア内のリアルタイム交通流を取得

道路リンクごとに 平均速度・混雑度（Jam Factor）・基準速度・信頼度 を返す

空間フィルタを使い対象エリアのみを絞って取得できる

代表的な利用シーン

地図上で色分けした渋滞状況の表示

ルートの所要時間計算や ETA 補正

混雑パターン分析や配車最適化

自前で「渋滞区間ポリライン」を生成して可視化

公式ドキュメント（概念）
https://www.here.com/docs/bundle/traffic-api-developer-guide-v7/page/topics/concepts/flow.html

B. Traffic Incidents（インシデント情報取得）

できること

交通インシデント（事故・工事・通行止め等）の情報を取得

位置・種別・説明など詳細を含む

しかし日本では注意点

公式 Coverage で Japan が含まれるのは Flow であり、Incident の提供有無は必ずしも保障されません。

公式のカバレッジ一覧では Japan が Traffic Coverage（Flow 含む）として ✓ となっているため Flow は確実に利用可能です。
https://www.here.com/docs/bundle/traffic-api-developer-guide-v7/page/topics/coverage-information/traffic.html

代表的な利用シーン

事故・イベント情報をリアルタイムに取得して通知

夜間工事や閉鎖によるルート迂回の判断（ただし日本では制限あり）

C. Traffic Coverage（どの地域で何が提供されるか）

できること

Traffic Flow / Traffic Incidents の提供可能性を国・地域ごとに確認

事前に Coverage を確認して、どの API を利用できるか判定する

日本について

Japan は Coverage リストで該当するコードとして含まれているため、Traffic Flow（交通流）は利用可能です。
https://www.here.com/docs/bundle/traffic-api-developer-guide-v7/page/topics/coverage-information/traffic.html

5. まとめ（日本における Traffic API の整理）
項目	状況
Flow（交通流）	日本でも利用可能（Traffic Coverage に記載あり）
Incident（事故・イベント）	提供可能だが Coverage によって変動（日本は必ずしも全対応ではない可能性）
Data Source	自社統合のリアルタイムデータ（プローブ・センサー等）
主な用途	渋滞可視化・ETA 補正・配車分析・ルート最適化
